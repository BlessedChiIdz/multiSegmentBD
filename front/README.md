# Frontend (multiSegmentBD)

Веб-интерфейс в стиле DBeaver: слева сегменты и дерево схемы, справа SQL-редактор и результаты по вкладкам сегментов.

Стек: **React** + **TypeScript** + **Material UI**.

## Запуск

1. Запустите бэкенд на порту 8080 (из каталога `back/`).
2. Установите зависимости и стартуйте dev-сервер:

```bash
cd front
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Запросы к API проксируются на `http://127.0.0.1:8080` (см. `"proxy"` в `package.json`).

Другой URL API:

```bash
REACT_APP_API_URL=http://localhost:8080 npm start
```

## Возможности

- Дерево **public → таблицы → колонки** (тип, NULL, PK)
- Двойной клик по таблице — `SELECT * … LIMIT 100`
- Двойной клик по колонке — вставка имени в редактор
- Выбор сегментов для запроса (пустой выбор = все)
- **Run** или `Ctrl+Enter` — выполнение SQL
- Вкладки результатов по каждому сегменту (таблица / ошибка)
